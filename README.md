# Ex. 12 - Full Stack Web Application using Node.js, React.js and MongoDB

Web Technology Lab (23CS2049).

Student management app: Express REST API (`backend/`) with MongoDB storage and a React/Vite front end (`frontend/`).

**Run:** Start MongoDB. In `backend/`: copy `.env.example` to `.env`, `npm install`, `node server.js`. In `frontend/`: `npm install`, `npm run dev`, open http://localhost:5173

Live page: https://noelms.github.io/Exp12_Web_Tech/

The page shows the source and output captured from a real local run; this exercise needs a local server or MongoDB, so it cannot run on GitHub Pages itself.
